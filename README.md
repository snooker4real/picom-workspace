# picom-workspace

**Stack** : Java 11, Maven, Spring Boot 2.6.3, MySQL, JWT

## Démarrage

### `picom-business-case-api/`

```bash
cd picom-business-case-api
./mvnw clean install   # construire et tester
./mvnw spring-boot:run   # démarrer l'application
./mvnw test   # lancer les tests
```

picom-business-case-api/
